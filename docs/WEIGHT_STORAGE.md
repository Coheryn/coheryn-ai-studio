# Bounded positional weight reads

The CPU storage candidate uses an owned read-only file handle and explicit offsets for tensor reads. On macOS/Linux it uses stable [Unix `read_exact_at`](https://doc.rust-lang.org/std/os/unix/fs/trait.FileExt.html#method.read_exact_at). On Windows it completes stable [`seek_read`](https://doc.rust-lang.org/std/os/windows/fs/trait.FileExt.html#tymethod.seek_read) calls, retrying interruptions and advancing only by the bytes actually returned. Other targets retain the existing locked reader and remain outside the required CPU qualification matrix.

The supported OS paths remove Coheryn's shared seek/read lock and the separate seek operation. Windows updates its file cursor internally; storage owns the handle and performs every transfer with an explicit offset after header validation. The OS can still serialize physical I/O. Tensor computation keeps its existing shared-tile and worker boundaries, so model-level improvement requires measurement.

`Storage::read` checks the complete byte range and overflow before I/O. A transfer must fill the requested buffer to return success. Truncation and I/O failure produce `MODEL_CHANGED`; callers must discard a partially filled buffer on error. Length/modification checks continue at the existing execution boundaries, including temporal-patch views. Buffered reads use admitted tensor scratch; successful transfers add no heap buffer, mapping, model-sized copy or additional file handle. Architecture, tensor encoding and numeric acceptance contracts retain their own qualification requirements.

Ordinary regressions cover four interleaved readers with independently checked offsets/lengths, empty and EOF boundaries, overflow, truncation, short reads, interruptions and nonretryable errors. The existing temporal-patch fixture checks channel/time byte order. These checks must execute on each native CPU target; configuring CI or passing a simulated read helper does not qualify the Windows system call path. Native text benchmark and full numerical model checks remain separate. The candidate has no measured model-throughput claim until those runs are reviewed.
